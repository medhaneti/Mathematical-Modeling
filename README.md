# Mathematical-Modeling
Environmental Optimization of Food Taxation in Canada

- Built a mathematical optimization model to minimize food-related CO₂ emissions using tax/subsidy policies across 14 categories
- Modeled consumer behavior using the Almost Ideal Demand System (AIDS) with price elasticity data from Statistics Canada
- Conducted simulations of the model using Python coding
- Implemented constrained optimization (SciPy SLSQP) with economic and policy constraints, including budget and GDP impact caps
- Achieved 12.4% reduction in emissions while reducing household food spending by 3.79%
- Conducted sensitivity analysis to evaluate policy effectiveness under changing constraints
